## About

I build websites for clients with WordPress and Elementor, and spend the rest of my time turning my own ideas into real products: web apps with Next.js and desktop apps with Tauri and Rust. I like software that is calm, fast, and private by design, and I ship everything myself, from the first sketch to the release.
